# glovebox-journal-media

Public media hosting for **The Glovebox Journal** social video assets.

`pilot/post-01.mp4` … `pilot/post-12.mp4` — 1080x1920, 30fps, silent. These are the
finished short-form videos for the brand's first publishing run; they are hosted here so
the scheduling tool can fetch them over HTTPS. Nothing else is stored in this repository.

The Glovebox Journal is an AI-produced format from Money Makers.
